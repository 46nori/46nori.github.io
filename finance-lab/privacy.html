Fetch-Gmail プライバシーポリシー

最終更新日：2026年10月12日

Fetch-Gmail（以下「本アプリ」）は、開発者本人だけが使う個人用ツールです。このページでは、本アプリが Google ユーザーデータをどのように扱うかを説明します。

1. 取得するデータ

  • 開発者本人の Gmail アカウントにある、特定のラベルが付いたメールマガジンのメッセージ（件名、送信元、日時、本文）。
  • 使用する権限は読み取り専用の https://www.googleapis.com/auth/gmail.readonly だけです。
  • 上記ラベル以外のメール、連絡先、カレンダーなど、ほかのデータは取得しません。

2. 利用目的

  • メールマガジンの本文を保存し、発行日ごとに整理すること。
  • 本文を要約し、市況の把握や投資判断の材料として開発者本人が読むこと。

広告、データの販売、利用者のプロファイリングには使いません。

3. 保存

取得したデータは開発者本人のコンピューターだけに保存します。認証トークンも同じコンピューター上に、本人だけが読める権限で保存します。

4. 第三者への提供

データを販売・共有することはありません。ただし、要約のために、取得したメールマガジンの本文を AI サービス（Anthropic の Claude）に送ります。送るのは上記ラベルのメールマガジン本文だけで、AI モデルの学習には使わせない設定で利用します。

5. 保存期間と削除

データは開発者本人が削除するまで保存します。Google アカウントのサードパーティ接続の管理ページで本アプリへのアクセスを取り消すと、本アプリは以後メールを取得できなくなります。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

7. お問い合わせ

GitHub Issues からご連絡ください。

Fetch-Gmail Privacy Policy

Last updated: October 12, 2026

Fetch-Gmail ("the app") is a personal tool used only by its developer. This page explains how the app handles Google user data.

1. Data accessed

  • Newsletter messages under a specific label in the developer's own Gmail account (subject, sender, date, and body).
  • The only scope used is the read-only https://www.googleapis.com/auth/gmail.readonly.
  • The app does not access any other email, contacts, calendar, or other data.

2. How the data is used

  • To save newsletter text and organize it by issue date.
  • To summarize the text so the developer can read it as material for understanding market conditions and making investment decisions.

The data is not used for advertising, sold, or used to profile anyone.

3. Storage

Data is stored only on the developer's own computer. The authorization token is stored on the same computer with permissions that only the developer can read.

4. Sharing with third parties

The data is not sold or shared. For summarization, however, the text of the newsletters is sent to an AI service (Anthropic's Claude). Only the bodies of newsletters under the label above are sent, and the service is used with settings that do not allow the data to be used to train AI models.

5. Retention and deletion

Data is kept until the developer deletes it. Revoking the app's access on the third-party connections page of the Google Account stops the app from retrieving any further email.

6. Google API Services User Data Policy

The app's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Contact

Please contact us via GitHub Issues.
